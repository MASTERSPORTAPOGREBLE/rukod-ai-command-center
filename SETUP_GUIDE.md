## 🚀 Быстрый старт

### Системные требования
- Node.js 18+ 
- npm или yarn
- Современный браузер (Chrome, Firefox, Safari, Edge)

### Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone <your-repo-url>
   cd ai-ide
   ```

2. **Установите зависимости:**
   ```bash
   npm install
   ```

3. **Создайте файл окружения:**
   ```bash
   cp .env.example .env
   ```

4. **Настройте переменные окружения в `.env`:**
   ```bash
   # Обязательно для работы ИИ
   VITE_GEMINI_API_KEY=your_gemini_api_key_here
   
   # Опционально для интеграций
   VITE_REPLIT_TOKEN=your_replit_token_here
   VITE_GITHUB_TOKEN=your_github_token_here
   
   # Ключ шифрования (можно оставить по умолчанию для разработки)
   VITE_ENCRYPTION_KEY=your_custom_encryption_key
   ```

5. **Запустите проект:**
   ```bash
   npm run dev
   ```

6. **Откройте браузер:**
   Перейдите по адресу `http://localhost:5173`

## 🔑 Настройка API ключей

### Получение Gemini API Key (обязательно)

1. Перейдите на [Google AI Studio](https://makersuite.google.com/app/apikey)
2. Войдите в аккаунт Google
3. Создайте новый API ключ
4. Скопируйте ключ (начинается с `AIza`)

### Настройка в IDE

Есть два способа настройки API ключей:

#### Способ 1: Переменные окружения (рекомендуется для разработки)
Добавьте ключи в файл `.env`:
```bash
VITE_GEMINI_API_KEY=AIza_your_actual_key_here
```

#### Способ 2: Через интерфейс IDE (рекомендуется для пользователей)
1. Откройте IDE
2. Перейдите в раздел "Настройки" (левая панель)
3. Введите ваш Gemini API ключ
4. Нажмите "Сохранить ключи"

### Опциональные интеграции

#### Replit Token
1. Войдите в [Replit](https://replit.com)
2. Перейдите в Account Settings
3. Создайте новый токен в разделе API

#### GitHub Token
1. Перейдите в [GitHub Settings](https://github.com/settings/tokens)
2. Создайте Personal Access Token
3. Выберите необходимые права доступа

## ☁️ Интеграция с облачными сервисами

1. Настройте Replit токен

- ✅ Создается README с инструкциями

## 🔒 Безопасность

### Шифрование ключей
- Все API ключи шифруются перед сохранением
- Используется XOR шифрование с пользовательским ключом
- Ключи хранятся только в localStorage браузера

### Приоритет настроек
1. Переменные окружения (.env файл)
2. Сохраненные в браузере ключи
3. Ключи, введенные в интерфейсе

### Рекомендации по безопасности
- 🔐 Не делитесь API ключами
- 🔄 Регулярно обновляйте токены
- 🗑️ Используйте кнопку "Очистить все" при смене устройства
- 🔒 Используйте .env файл для разработки

## 🐛 Решение проблем

### Ошибка "API ключ не настроен"
- Проверьте формат ключа (должен начинаться с `AIza`)
- Убедитесь что ключ введен правильно
- Попробуйте пересоздать ключ в Google AI Studio

### Ошибка "Неверный формат API ключа"
- Ключ Gemini должен начинаться с `AIza`
- Проверьте что скопировали ключ полностью
- Убедитесь что нет лишних пробелов

### Проблемы с Monaco Editor
- Обновите браузер до последней версии
- Очистите кэш браузера
- Проверьте что JavaScript включен

### Проблемы с интеграциями
- Проверьте права доступа токенов
- Убедитесь что токены активны
- Попробуйте пересоздать токены

### Проблемы с производительностью
- Закройте неиспользуемые файлы
- Очистите историю чата
- Перезагрузите страницу
