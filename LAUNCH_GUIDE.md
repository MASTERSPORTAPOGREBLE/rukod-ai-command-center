# 🚀 Подробная инструкция запуска AI IDE

## 📋 Быстрый старт (5 минут)

### 1. Клонирование проекта
```bash
# Если у вас есть Git репозиторий
git clone <your-repo-url>
cd ai-ide

# Или просто скачайте и распакуйте архив
```

### 2. Установка зависимостей
```bash
# Убедитесь что Node.js установлен (версия 16+)
node --version
npm --version

# Установка зависимостей
npm install
```

### 3. Настройка API ключа
```bash
# Создайте файл .env (если его нет)
cp .env.example .env

# Откройте .env и добавьте ваш API ключ
# VITE_GEMINI_API_KEY=API_GMN  (уже настроен!)
```

### 4. Запуск
```bash
# Запуск в режиме разработки
npm run dev

# Откройте браузер по адресу http://localhost:5173
```

## 🔧 Основные функции

### 1. 🤖 Генерация кода с ИИ
```
Примеры запросов:

"Создай React компонент кнопки с анимацией"
"Сделай простую HTML страницу с формой"

```

```
"Нарисуй логотип для стартапа"
```

- ИИ автоматически улучшает ваш код
- Находит и исправляет ошибки

## ⚙️ Расширенные настройки

### API Ключи (в настройках)
```
🔑 Доступные сервисы:

✅ Gemini 2.5 Flash (настроен: API_GMN)
⭕ DeepSeek Coder (бесплатно до 10M токенов)
⭕ Qwen Coder (бесплатная китайская модель)
⭕ Hugging Face (для генерации изображений)
```

### Получение дополнительных ключей:

#### DeepSeek (бесплатно!)
1. Идите на [platform.deepseek.com](https://platform.deepseek.com)
2. Регистрируйтесь
3. Получите API ключ
4. Добавьте в настройки: `VITE_DEEPSEEK_API_KEY`

#### Hugging Face (для изображений)
1. Идите на [huggingface.co](https://huggingface.co/settings/tokens)
2. Создайте аккаунт
3. Создайте токен
4. Добавьте: `VITE_HUGGINGFACE_API_KEY`

## 🔍 Решение проблем

### ❌ "API ключ не работает"
```bash
# Проверьте файл .env
cat .env

# Убедитесь что ключ правильный
# VITE_GEMINI_API_KEY=API_GMN

# Перезапустите сервер
npm run dev
```

### ❌ "Предпросмотр не работает"
```bash
# Проверьте консоль браузера (F12)
# Убедитесь что код валидный
# Попробуйте простой HTML:

<!DOCTYPE html>
<html>
<body>
    <h1>Тест</h1>
</body>
</html>
```

### ❌ "Ошибка установки зависимостей"
```bash
# Очистите кэш npm
npm cache clean --force

# Удалите node_modules
rm -rf node_modules package-lock.json

# Переустановите
npm install
```

### ❌ "APK не создается"
```bash
# Установите Android Studio
# Настройте ANDROID_HOME
export ANDROID_HOME=$HOME/Android/Sdk

# Или используйте PWA версию
npm run serve
```
