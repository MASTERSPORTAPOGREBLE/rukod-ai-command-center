# Call of War - Стратегическая игра

## Описание

Стратегическая игра в реальном времени, созданная в стиле Call of War. Игра представляет собой браузерную стратегию с HTML5 Canvas картой и игровым движком на TypeScript (в стиле C++).

## Основные особенности

### 🗺️ Игровая карта
- **HTML5 Canvas** для отрисовки карты мира
- **Интерактивная карта** с зумом и панорамированием
- **Европейские провинции** с реалистичными данными
- **Разные типы провинций**: столицы, промышленные центры, порты

### ⚔️ Военная система
- **8 типов войск**: пехота, бронетехника, артиллерия, истребители, бомбардировщики, флот, подводные лодки, ПВО
- **Боевая система** с расчетом атаки, защиты, морали и опыта
- **Перемещение войск** по карте в реальном времени
- **Оборонительные бонусы** от укреплений

### 🏭 Экономическая система
- **6 типов ресурсов**: людские ресурсы, сталь, нефть, продовольствие, деньги, исследования
- **Производственные здания**: заводы, казармы, порты, аэродромы, лаборатории
- **Инфраструктура** влияет на производство
- **Мораль населения** влияет на эффективность

### 🔬 Система исследований
- **6 ветвей исследований**: пехота, бронетехника, авиация, флот, промышленность, экономика
- **Прогрессивная система** улучшений
- **Очереди исследований** с временными затратами

### 🤝 Дипломатия
- **5 типов отношений**: война, мир, союз, пакт о ненападении, торговое соглашение
- **Интерактивная дипломатическая панель**
- **Система сообщений** между игроками

### 🤖 Искусственный интеллект
- **Умный ИИ** для компьютерных игроков
- **Автоматическое производство** войск и зданий
- **Стратегическое планирование** экспансии

## Техническая архитектура

### 🎮 Игровой движок (C++ стиль в TypeScript)
```typescript
class GameEngine {
  - gameLoop(): void          // Основной игровой цикл
  - updateProduction(): void  // Обновление производства
  - updateMovement(): void    // Движение войск
  - processBattles(): void    // Обработка боев
  - updateAI(): void          // ИИ логика
}
```

### 🎨 Фронтенд
- **React 18** с TypeScript
- **HTML5 Canvas** для карты
- **Tailwind CSS** для стилизации
- **Lucide React** для иконок
- **React Router** для навигации

### 📊 Модели данных
- **Типизированные интерфейсы** для всех игровых объектов
- **Система событий** для игровых действий
- **Состояние игры** с полной сериализацией

## Игровой процесс

### 🎯 Цель игры
Захватить максимальное количество территорий и стать доминирующей силой в мире.

### 📋 Игровые действия
1. **Управление провинциями**: строительство, производство, развитие
2. **Военные операции**: создание армий, атаки, оборона
3. **Дипломатия**: заключение союзов, торговые соглашения
4. **Исследования**: разработка новых технологий
5. **Экономика**: управление ресурсами и производством

### ⏰ Игровое время
- **Реальное время** с регулируемой скоростью
- **День игры** = настраиваемое время (по умолчанию 10 минут)
- **Пошаговые обновления** каждый игровой день

## Страны и игроки

### 🏛️ Доступные страны
1. **Германия** (Берлин) - промышленная мощь
2. **Франция** (Париж) - исследовательский центр  
3. **Великобритания** (Лондон) - морская сила
4. **Россия** (Москва) - территориальный гигант
5. **Италия** (Рим) - средиземноморская сила
6. **Австро-Венгрия** (Вена) - центральная Европа

### 👥 Типы игроков
- **Человек-игрок**: полное управление
- **ИИ-игрок**: автоматическое управление

## Пользовательский интерфейс

### 🖥️ Основной экран
- **Игровая карта** (центральная область)
- **Панель ресурсов** (верх экрана)
- **Боковые панели**: провинции, войска, дипломатия, события

### 📱 Адаптивный дизайн
- **Полноэкранный режим** для игры

## Запуск игры

### 🚀 Быстрый старт
1. Откройте приложение
2. На главной странице нажмите **"Стратегическая игра"**
3. Дождитесь загрузки мира
4. Начинайте играть за Германию!

### ⚙️ Настройки
- Скорость игры настраивается в игровом движке
- Сложность ИИ можно изменить в коде
- Количество ресурсов настраивается в данных мира
